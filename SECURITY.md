# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability or a bypass in `envguard`'s secret scanner or parser, please open a private security advisory on GitHub rather than filing a public issue with exploit details.

We aim to acknowledge reports within 72 hours and release a fix as soon as possible.
